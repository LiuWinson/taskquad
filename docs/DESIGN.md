# TaskQuad 设计规范（Web 与鸿蒙端共同遵守）

应用名称：**任务四象限**（TaskQuad）。界面语言：简体中文。

## 1. 四象限配色与含义

| key | 标签 | 主色 | 含义 |
| --- | --- | --- | --- |
| IU | 重要且紧急 | `#E5484D`（红） | 立即处理 |
| IN | 重要不紧急 | `#3B82F6`（蓝） | 计划安排 |
| NU | 紧急不重要 | `#F59E0B`（琥珀） | 尽快处理/委托 |
| NN | 不重要不紧急 | `#8B8F98`（灰） | 空闲时处理 |

四象限看板布局（重要=上行，紧急=左列）：

```
+----------------+----------------+
| IU 重要且紧急  | IN 重要不紧急  |
+----------------+----------------+
| NU 紧急不重要  | NN 不重要不紧急|
+----------------+----------------+
```

## 2. 页面结构

### 顶部导航
应用标题「任务四象限」+ 三个视图切换：**四象限** / **列表** / **归档**，右侧设置入口（齿轮图标/「设置」）。

### 视图一：四象限看板
- 2×2 网格，每个象限一个卡片：色条 + 象限名 + 未完成任务数。
- 卡片内任务行：勾选框（完成打钩）+ 标题 + 截止时间徽标 + 象限色点缀。
- 已逾期（`dueAt < now` 且未完成）的截止时间用红色加粗显示。
- 每个象限卡片底部「+ 添加任务」按钮（新增时自动带入该象限）。
- 顶部提示文案：按住任务可拖动排序/换象限。

#### 拖拽交互（桌面端/浏览器，HTML5 Drag & Drop）
- 任务行 `draggable`；拖动中该行 40% 透明度，悬停的目标象限卡片显示虚线边框。
- 拖到某任务行上方/下方：该行顶部/底部显示插入指示线，松手插入该位置。
- 拖到卡片空白区（含空卡片）：追加到该象限末尾。
- 提交方式：`PATCH /api/tasks/:id { "quadrant": <目标象限>, "order": <排序值> }`，order 取相邻两项中点（首位置 = 前项-1，末位置 = 末项+1，空列表 = 当前时间戳）；同象限排序仅提交 `order`。
- 排序语义：每个象限内按 `order` 升序展示（旧数据由服务端以 createdAt 时间戳补齐）。
- 移动端（<640px）：触屏设备无原生拖拽，此功能在手机浏览器不可用（鸿蒙原生 App 后续版本支持）。

### 视图二：列表视图
- 未完成任务按 `dueAt` 升序，无截止时间排在最后。
- 每行：勾选框 + 标题 + 象限彩色小标签 + 截止时间（逾期红色）+ 提醒时间（如有，显示小铃铛）。
- 顶部「+ 新建任务」按钮。

### 视图三：归档视图
- 子标签切换：**本周 / 本月 / 本季度**（对应 `GET /api/archive?period=`）。
- 已完成任务按完成时间降序，可按天分组（显示「M月d日」分组头）。
- 每行：标题 + 象限标签 + 完成时间。
- 操作：**恢复**（`PATCH completed=false`，任务回到看板/列表）、**删除**。
- 顶部显示该周期完成数量（如「本周已完成 5 项」）。

### 编辑/新建任务对话框
字段：
1. 标题（必填）
2. 备注（多行，可选）
3. 四象限（4 个可选色块，单选，默认 IU）
4. 需要完成时间（截止时间，日期+时间选择，可留空）
5. 提醒时间（日期+时间选择，可留空；Web 端提供快捷按钮：截止前 5 分钟 / 15 分钟 / 1 小时 / 1 天——仅在已选截止时间时可用）
6. 操作：保存 / 取消；编辑已有任务时另有删除按钮。

勾选完成交互：点击勾选框立即调用 `PATCH completed=true`，行样式变为删除线/变灰后移入归档（无需确认）。

## 3. 设置与连接（鸿蒙端）

- 鸿蒙端需要配置服务器地址：`http://<Windows 局域网 IP>:8788`，保存到本地偏好。
- 提供「测试连接」按钮（调用 `GET /api/health`），成功显示绿色提示，失败显示红色错误。
- 主界面顶部显示连接状态（已连接/未连接）。
- 默认端口 8788。

## 4. 视觉风格

- 浅色背景（`#F5F6F8`），白色卡片，圆角 12px，细边框，轻投影。
- 主色点缀使用象限色；主操作按钮可用深蓝 `#2F6BFF` 或中性深灰。
- 已逾期时间：红色 `#E5484D` 加粗。
- 完成任务：标题删除线 + 60% 透明度。
- 字体：系统默认无衬线字体。移动端（<640px）四象限网格退化为单列。

## 5. 鸿蒙端提醒机制

- App 每次同步到任务列表后，本地对账提醒：
  - 未完成且 `remindAt` 在未来 → 用 `reminderAgentManager` 发布 `ReminderRequestTimer`（`triggerTimeInSeconds = remindAt/1000`），`title = 任务提醒`，`content = 任务标题`。
  - 已完成、无 `remindAt`、或 `remindAt` 已过 → 取消对应 reminderId。
  - reminderId 由任务 id 稳定哈希得到（正整数，< 2^31）。
- 首次启动请求提醒权限（`ohos.permission.PUBLISH_AGENT_REMINDER`，module.json5 中声明）。
- App 在前台每 30 秒刷新一次任务列表；进入页面时立即刷新。

## 6. 鸿蒙端工程约定

- Stage 模型，DevEco Studio 5.x，`modelVersion: "5.0.0"`，`compatibleSdkVersion: "5.0.0(12)"`。
- bundleName：`com.example.taskquad`。
- 所有 .ets 源文件严格 ArkTS 语法（禁止 `any`、禁止未类型化对象字面量、禁止解构、`as` 断言需注意）。
- 网络权限 `ohos.permission.INTERNET`、提醒权限 `ohos.permission.PUBLISH_AGENT_REMINDER` 在 module.json5 声明。
